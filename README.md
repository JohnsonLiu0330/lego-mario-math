# 🏰 樂高瑪利歐的 99 乘法大冒險 (Lego Mario Math Adventure)

專為 6 歲小朋友設計的互動式 99 乘法學習遊戲！結合孩子最愛的「樂高積木 (LEGO)」與「超級瑪利歐 (Super Mario)」元素，透過趣味動畫、積木點陣視覺化與即時音效，讓數學學習變得像玩闖關遊戲一樣好玩！

---

## 🌟 核心特色 (專為 6 歲孩童量身打造)

1. **🧱 樂高積木點陣視覺化（理解乘法本質）**
   - 6 歲小朋友常常只是死背「三四十二」，但不知其意。
   - 本遊戲提供「查看樂高積木點陣」功能：例如 $3 \times 4$ 會顯示「3 排、每排 4 顆」的立體樂高顆粒底板。
   - 小朋友可以親手點擊顆粒，逐一數出 1, 2, 3... 12，將抽象的乘法轉為直觀的「空間面積與分組計數」概念！

2. **🍄 超級瑪利歐闖關與獎勵機制**
   - **問號磚塊出題**：經典金黃色問號磚，充滿探索驚喜。
   - **立體樂高按鈕**：直觀大按鈕（紅、藍、綠、黃 4 色樂高塊），專為 iPad 觸控手指設計。
   - **金幣與城堡建造**：答對時彈出金幣（🪙 +10）並累積城堡積木，答對 8 題即可升起瑪利歐城堡旗幟！
   - **答錯不氣餒**：溫和的彈簧音效與提示引導，不扣分、無時間倒數壓力，鼓勵孩子再算一次。

3. **📢 雙語音支援（免外部資源，離線可用）**
   - **8-bit 復古遊戲音效**：使用 Web Audio API 即時合成金幣聲、升旗勝利號角、樂高拼砌卡榫聲。
   - **中文語音朗讀**：支援台灣中文發音（如「3 乘以 4 等於多少呢？」與「答對了！三四十二！」）。

4. **🎮 三種遊戲模式**
   - **🏰 冒險闖關**：循序漸進的世界地圖（世界 1 先練 2 與 5 的規律，接著練 3 與 4，再到 6~9 與混合大挑戰）。
   - **🎯 乘數練習**：可自由挑選單一數字（如專練 7 的乘法）。
   - **🧱 積木實驗室**：自由拉動排數與顆粒滑桿，即時看見積木大小變化與乘法算式，培養數感。

## 🚀 如何發布到 GitHub Pages（免費且讓 iPad 隨時開啟）

只要 3 分鐘，即可將遊戲放到 GitHub 上，並獲得一個專屬的網址：

### 步驟一：在 GitHub 建立 Repository
1. 打開瀏覽器前往 [GitHub](https://github.com/) 並登入帳號。
2. 點擊右上角的 **「+」** 按鈕，選擇 **「New repository」**。
3. 在 **Repository name** 輸入喜歡的名稱（例如：`lego-mario-math`）。
4. 勾選 **「Public」**（公開）。
5. 點擊最下方的 **「Create repository」**。

### 步驟二：上傳遊戲檔案
1. 在建立好的專案頁面中，點擊 **「uploading an existing file」**（上傳現有檔案）。
2. 將此資料夾內的 `index.html`（以及 `.nojekyll`）拖曳到網頁中。
3. 點擊下方的綠色按鈕 **「Commit changes」**。

### 步驟三：開啟 GitHub Pages 網頁託管
1. 在專案上方選單點擊 **「Settings」**（設定）。
2. 在左側側邊欄找到並點擊 **「Pages」**。
3. 在「Build and deployment」底下的 **Branch**：
   - 將 `None` 切換成 **`main`**（或 `master`）。
   - 資料夾保持 `/ (root)`。
   - 點擊 **「Save」**。
4. 等待約 1~2 分鐘後重新整理頁面，上方會出現綠色的網址提示：
   `Your site is live at https://<你的帳號>.github.io/lego-mario-math/`

## 📱 iPad 最佳體驗設定（加到主畫面，像 App 一樣全螢幕遊玩）

為了讓 6 歲小朋友能自己一鍵點開、不受瀏覽器網址列干擾：

1. 在 iPad 上使用 **Safari 瀏覽器** 開啟剛才建立好的 GitHub Pages 網址。
2. 點擊 Safari 右上角（或上方工具列）的 **「分享」圖示**（一個方框帶向上箭頭 ⎋）。
3. 在選單中往下滾動，點擊 **「加入主畫面」(Add to Home Screen)**。
4. 名稱預設為「乘法大冒險」，圖示為專屬的問號積木圖示，點擊右上角 **「新增」**。
5. 桌面即會出現獨立的 App 圖示！點開即為**無網址列全螢幕模式**，隨時隨地離線也能暢玩！
